# App Layer

Day la code that cua san pham, bao gom UI, API, va database.

## Nguyen tac

- App goi AI qua API, khong thuc thi rules markdown truc tiep.
- App giu toan bo business logic deterministic:
  - validation mandatory fields
  - permission
  - idempotency
  - persistence

## Cac thanh phan

- frontend/: giao dien va user interaction
- backend/: API, orchestration, validation, transaction flow
- database/: schema, migration, indexing, storage policy
